# Data Cleaning Project_Company Layoff Dataset
📄 Overview

This project demonstrates my ability to clean, preprocess, and standardize raw data using SQL.
I worked with a dataset containing information about global company layoffs, focusing on removing duplicates, handling missing data, standardizing text fields, fixing inconsistent data formats, and preparing the data for analysis.

This project was completed as part of my Data Analytics / Data Engineering internship practice to strengthen my SQL data cleaning skills.

🧠 Objectives

The goal of this project was to:

Remove duplicate records

Standardize data formats (text, date, country names, etc.)

Handle missing or null values

Fix inconsistent entries (e.g., “CryptoCurrency” → “Crypto”)

Prepare a clean, analysis-ready dataset
